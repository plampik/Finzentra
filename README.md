# Finzentra

Адаптивный frontend Finzentra для учета финансов по проектам. При входе
открывается главный экран сервиса с переходами к регистрации и входу. В демо-
кабинете доступны разделы «Дашборд», «Операции», «Проекты» и «Настройки»,
отчеты P&L и Cash Flow, фильтры по периоду, проекту и типу операции.
Интерфейс адаптируется для телефонов, планшетов и больших экранов; мобильная
навигация учитывает безопасные зоны устройств.

## Запуск и проверки

```bash
npm install
npm run dev
npm run typecheck
npm run build
```

GitHub Actions автоматически выполняет установку зависимостей через `npm ci`,
проверку TypeScript и production-сборку при каждом push и pull request.
Для запуска приложения локально нужен Node.js 22.

Для production-сборки приложение публикует PWA manifest и service worker.
Service worker кэширует оболочку и статические ресурсы; данные операций остаются
в `localStorage` и не передаются в кэш service worker.

## Хранение данных

В проекте нет backend или серверной авторизации. Экраны регистрации и входа
проверяют ввод в браузере, но не создают аккаунты и не отправляют или сохраняют
пароли. Переход в кабинет доступен как демонстрационный режим. Проекты,
категории и операции хранятся локально в браузере, поэтому не синхронизируются
между устройствами и пользователями. Для рабочей авторизации и синхронизации
нужна серверная реализация и интеграция API.
